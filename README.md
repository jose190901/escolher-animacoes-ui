# Escolher animações UI

Skill para escolher e integrar animações de [Unlumen UI](https://ui.unlumen.com/components), [Magic UI](https://magicui.design/docs/components), [SmoothUI](https://smoothui.dev/docs/components), [Retro UI](https://retroui.io/) e [Canvas UI](https://canvasui.dev/components) em sites e apps web.

A skill avalia a interface e escolhe uma animação que combina com o projeto, verificando compatibilidade, acessibilidade e desempenho antes de integrar.

## Instalação

Copie a pasta deste repositório para o diretório de skills do seu agente:

- **Codex:** `~/.codex/skills/escolher-animacoes-ui/`
- **OpenCode:** `~/.config/opencode/skills/escolher-animacoes-ui/`

Mantenha `SKILL.md` na raiz da pasta e `agents/openai.yaml` na subpasta `agents`. A skill já está instalada localmente nesses dois agentes no computador do autor.

## Uso

Peça ao agente para escolher uma animação para uma página ou componente. Ele deve ler o projeto, consultar a documentação atual do catálogo escolhido, integrar o efeito e verificar o resultado em desktop e celular.
